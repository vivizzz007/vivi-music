### New Features
- Added seamless audio Crossfade feature for smooth track transitions
- Added GitHub Star linking option in Settings dropdown menu
- Added BiniLyrics integration as a lyrics provider
- Added Unison lyrics provider
- Added new updater system
- Added InnerTubeX from Metrolist
- Added support to play YouTube Kids songs
- Added chips in Queue screen
- Added download animation to Album screen (Material Expressive)
- Upgraded Daily Discover section
- Quick Picks now shown at the top
- Added "Load only on Wi-Fi" option for Canvas to save cellular data, now located in Player Settings
- Added "Remove from library" global control directly into album context menus
- Added fullscreen Detailed Listening History view with granular 24-hour analytics and precise playback counters

### Improvements
- Redesigned History Screen top bar with an integrated permanent search box instead of a hidden search icon
- Integrated the Local/Remote history toggle directly into the search bar UI
- Removed Canvas showing in small box in Player V2 (Apple V17 style)
- Removed snackbar showing on update check
- Reduced app size from ~40 MB to ~30 MB
- Redesigned Library Mix layout to natively suppress album and playlist redundancies below StatCards
- Ripped out obsolete "Uploaded Playlist" parsing and sync modules
- Migrated the Data Saver toggle directly into Content Settings, and removed the standalone Data Saver screen
- Upgraded the side navigation bar in tablet mode to conform to new Material 3 Expressive WideNavigationRail guidelines
### Fixes
- Fixed severe library loading lag — background YouTube syncing now handled safely by the sync service
- Fixed lyrics height and rendering issue in Player V2
- Fixed JioSaavn streaming fallback matching returning wrong songs or subscription advertisements
- Enforced strict explicit content matching for JioSaavn streams
- Fixed search suggestions sporadically not loading until a manual refresh by resolving a ViewModel concurrency issue
- Eliminated severe scroll-freezing inside AutoMix and Library tabs by safely removing nested PullToRefresh indicators and `animateItem` allocations
- Fixed newly played local songs not appearing in the Remote History tab by refreshing it automatically on song change
