## Improvements & Fixes

### Bug Fixes
- Fixed an issue where the slim navigation bar failed to hide labels in landscape orientation
- Fixed an issue where unexpected or stale songs from previous queues could appear sandwiched in between album tracks when starting album playback
- Fixed an issue where deleting multiple songs from the queue while shuffle was enabled caused an `IndexOutOfBoundsException` crash
- Fixed an issue where the crash reporter process (`:crash`) could enter a recursive crash loop on unexpected errors
- Fixed an issue in the new player where playback controls distorted into tall vertical shapes and caused layout thrashing when pressing previous or next
- Fixed premature notification and star prompts triggering before initial setup wizard was completed
- Fixed an issue in Listen Together where the chat input box was positioned too low or cut off by the system navigation bar on various devices
- Resolved phantom bottom padding in the Listen Together chat screen by removing unused mini-player and navigation bar insets
- Fixed an issue where tapping the refetch button in the Lyrics Menu failed to display the loading shimmer/indicator
- Fixed an issue in Apple Music lyrics animation where active lines could momentarily dim and blur during phrase transitions while words were actively flowing
- Fixed an issue where a gray background and dark overlay appeared over Spotify Canvas in the new player, and added smooth blurred artwork backdrop transitions when opening lyrics
- Fixed an `IllegalStateException` crash during background worker initialization on Android 17 (API 37) by implementing `Configuration.Provider` in `App`
- Fixed an issue where settings switches momentarily animated and flickered when opening settings screens
- Fixed an issue where adding songs to a playlist failed to sync to YouTube or were removed during background sync for logged-in accounts

### Improvements
- Added persistence for playback tempo and pitch settings across app sessions and player restarts
- Consolidated player subsystem by removing legacy duplicate implementations (`Player_v2`, `Queue_v2`, `Lyrics_v2`, and associated landscape/motion variants)
- Rewrote player and mini-player blur background using high-performance off-thread box blur engine with memory caching and contrast gradient scrim, enabling smooth 60/120 FPS rendering across all Android versions
- Enhanced lyrics engine with automatic in-between instrumental gap detection for breaks of 4 seconds or longer across word-synced and line-synced lyrics
- Improved Musixmatch RichSync and BiniLyrics syllable conversions to include precise closing line timestamps (`<te>`), enabling exact word-by-word animations and accurate pause detection
- Cleaned up unused and redundant libraries to reduce app size and improve build performance:
  - Removed `Lottie` and replaced the animated settings button with a lightweight native vector drawable, removing `setting.json`
  - Removed unused `Haze` and `Jsoup` libraries
  - Removed redundant `org.json:json` dependency in favor of standard Android SDK APIs
  - Removed orphaned `Brotli` decompression dependency from InnerTube
  - Removed heavy offline dictionary dependencies (`Kuromoji` and `TinyPinyin`), saving ~16 MB of app size
- Replaced bundled dictionary romanization with a lightweight on-demand romanization engine:
  - Batched requests with persistent two-tier (memory + disk) caching so loaded lyrics work 100% offline
  - Expanded native romanization support to Malayalam, Chinese, Japanese, Korean, Cyrillic, Indic languages, and more
  - Added "Romanize all languages" master switch and Malayalam toggle in Romanization Settings
- Updated InnerTube `WEB_REMIX` client version to the latest live production release (`1.20261115.14.00`) to align with Google's modern search ranking and indexing model
- Improved online search accuracy and relevance ranking by dynamically prioritizing top entity matches (Artists, Albums, Songs) over generic video clips and preventing intended search results from being demoted
- Enhanced regional search precision by synchronizing `visitorData` session tokens with user geolocation (`gl`) settings to eliminate regional search bias
- Added Repair Mode to resolve playback and streaming issues, and save logs to the vivimusic/repairtool folder
- Automatically saves crash reports to the vivimusic/crashlog folder on unexpected errors
- Added real-time dynamic comment synchronization and Material 3 Expressive loading indicators
- Added `MoodThumbnailHelper` with parallel background preloading and two-level caching (in-memory + persistent disk storage) to instantly render mood and genre thumbnails on frame 1 without on-scroll loading delay
- Completely removed legacy suggestion scraping infrastructure and region settings (`AppleMusicScraper`, `SuggestionsViewModel`, `SuggestionRegionSheet`, and `TabNewsSuggestion`)
- Improved HomeScreen loading speed and fluidity: eagerly fetch home continuations in the background upon launch, eliminating the scroll-down-to-load requirement and bottom loading shimmer animations so all sections are available instantly
- Optimized thumbnail URL resizing in `YouTubeUtils` with statically precompiled regexes and eliminated main-thread logcat overhead, resolving on-scroll UI thread frame drops
- Offloaded queue and player state disk persistence in `MusicService` to a background I/O dispatcher, eliminating UI thread lockups and frame drops on playback start
- Added support for LRCLIB word-by-word synchronized lyrics (karaoke-style animations) using LRCLIB's YAML lyricsfile schema
- Upgraded KuGou lyrics provider with KRC word-by-word synchronized lyrics decryption and resilient collaborator search fallback
- Modernized Musixmatch lyrics provider: eliminated cold-start web scraping latency using direct Android client credentials, added multi-tier search fallback for cluttered YouTube video titles and featured artists, and prioritized word-synced (RichSync) candidate ranking over plain text lyrics
- Modernized YouTube Music lyrics pipeline: added structured `timedLyricsModel` extraction with authenticated session support to unlock synchronized lyrics when available, clean line-level parsing fallback, and added a toggle switch and custom ordering priority in Content Settings
