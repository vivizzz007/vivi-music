## Improvements & Fixes

### Bug Fixes
- Fixed an issue in Listen Together where the chat input box was positioned too low or cut off by the system navigation bar on various devices
- Resolved phantom bottom padding in the Listen Together chat screen by removing unused mini-player and navigation bar insets

### UI Improvements
- Improved edge-to-edge insets and keyboard transitions in the Listen Together chat screen using native Scaffold layout and adaptive system bar padding

### Improvements
- Added persistence for playback tempo and pitch settings across app sessions and player restarts
- Consolidated player subsystem by removing legacy duplicate implementations (`Player_v2`, `Queue_v2`, `Lyrics_v2`, and associated landscape/motion variants)
- Rewrote player and mini-player blur background using high-performance off-thread box blur engine with memory caching and contrast gradient scrim, enabling smooth 60/120 FPS rendering across all Android versions
- Cleaned up unused and redundant libraries to reduce app size and improve build performance:
  - Removed `Lottie` and replaced the animated settings button with a lightweight native vector drawable, removing `setting.json`
  - Removed unused `Haze` and `Jsoup` libraries
  - Removed redundant `org.json:json` dependency in favor of standard Android SDK APIs
  - Removed orphaned `Brotli` decompression dependency from InnerTube
