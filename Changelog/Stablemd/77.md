### Improvements
- Redesigned the "From the Community" playlist card layout for the Home Screen into a clean, compact, fully responsive Material 3 container
- Replaced the generic app notification icon with a dedicated system update alert icon in the settings screen when a new update is available
- Updated the miniplayer audio device icon to properly show the generic Bluetooth icon when a Bluetooth device is connected
- Added a new lyrics prioritization toggle that ensures word-synced or line-synced lyrics are automatically fetched over plain text across all available providers
- Rewrote the lyrics fetching engine to query all enabled providers concurrently, completely removing sequential loading delays
- Completely redesigned the Library screen layout, featuring grouped list cards, filter chips for precise browsing (Artists/Albums/Playlists), and a unified List/Grid toggle
- Added pull-to-refresh to the Library screen and a 1-minute automatic background sync to instantly retrieve liked songs, albums, and artists from YouTube Music
- Redesigned the History screen by embedding the search bar directly into the TopAppBar, replacing the generic search icon with a unified back arrow for a cleaner look

### Bug Fixes
- Fixed an issue where the YouTube remote history would fail to synchronize automatically after listening to a song locally
- Fixed an issue where some songs failed to play with a "No playable stream found" error by updating the underling InnerTube extractor library
- Fixed an issue where the Bini Lyrics provider would abruptly stop displaying lyrics after the first few seconds of a song
