## Improvements & Fixes

### UI Improvements
- Added an adaptive Expressive Announcement card to the Home screen with media banners, smooth animations, and a rich markdown bottom sheet
- Added an audio-safe in-app video preview player for announcements that starts muted and never interrupts active music playback
- Added dynamic action buttons (such as Telegram and GitHub links) to announcement sheets
- Added immersive auto-hiding controls for Spotify Canvas in the new player, vanishing after 4 seconds of inactivity and reappearing on tap
- Added smooth blurred artwork backdrop transitions when opening lyrics over Spotify Canvas in the new player
- Removed download, new release, and taste-based notification toggles from notification settings
- Restored Discord activity status (Listening, Playing, Watching, Competing), custom activity name, and button customization settings in Discord integration

### Improvements
- Added automatic announcement expiration by date/time, live CDN cache-busting, and animated vanishing when announcements expire or are removed
- Removed update download notifications
- Removed new release and taste-based background notification alert worker

### Bug Fixes
- Fixed an issue where a gray background appeared behind Spotify Canvas in the new player
- Fixed an issue where the queue would get permanently stuck on a single song when starting playback or when YouTube's radio (`RDAMVM`) endpoint failed to resolve
- Fixed a potential `NullPointerException` crash in InnerTube queue parsing when YouTube returns an unexpected watch next layout
- Added automatic seamless radio fallback recovery in the player service when queue loading fails, ensuring continuous playback instead of stopping after one track
- Fixed an issue in the new player where old player action buttons (lyrics, audio device, queue) appeared below the artwork in landscape mode
- Fixed an issue in the new player where the landscape album artwork thumbnail was oversized and overlapped the controls from the bottom queue bar
- Fixed an issue in the new player where Apple Music lyrics animation was pushed to the bottom of the screen by aligning its scroll anchor with MetroLyrics
- Fixed an issue in Apple Music lyrics animation where auto-scroll failed to track the active singing line on songs with a lyrics provider, and ensured auto-scroll reliably resumes when seeking or tapping lyrics
- Fixed an issue where albums failed to load or sync from YouTube Music
- Fixed missing songs in album tracklists
